# Research

Standalone reference material — not project documentation, not code. Open the
`.html` files directly in a browser.

- **[mft-market-field-guide.html](./mft-market-field-guide.html)** — a from-scratch
  field guide to the MFT market: how IBM Sterling, Progress MOVEit, Fortra
  GoAnywhere, and Couchdrop actually work day-to-day (partner onboarding, workflow
  building, monitoring), the protocols they speak (SFTP/FTPS/AS2/Connect:Direct/
  OFTP2/PeSIT), the 2023 MOVEit and GoAnywhere breaches, the compliance frameworks
  buyers demand, how enterprises evaluate and buy MFT, and a prioritized gap
  analysis for CloudFuze MFT against all of it. Built from a multi-source research
  pass (primary vendor docs, CISA, threat-intel writeups, Drummond Group's
  certification registry) — sourcing and confidence caveats are documented inline
  in the guide itself.
